# SiWarga

SiWarga is a resident administration and information system designed to help manage citizen data, document uploads, and administrative workflows in a more organized and efficient way.

Built as a fullstack web application with REST API architecture and responsive interface support.

---

## Features

- Authentication & Authorization
- Resident Data Management
- Family Card (KK) Upload
- CRUD Operations
- REST API Integration
- Responsive User Interface
- API Testing with Postman

---

## Tech Stack


### Backend
- Node.js
- Express.js
- MySQL

### Frontend
- React
- Axios
- Tailwind CSS


### Tools
- Postman
- Git & GitHub
